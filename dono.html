Ligar a tua chave GitHub (só uma vez)

Para a Área do Dono guardar o que mudas, precisa de uma chave do teu GitHub. Fica guardada cifrada com a tua palavra-passe.

  1. Abre github.com › criar chave (entra na tua conta se pedir).
  2. Nome: poh dono. Validade: escolhe a mais longa.
  3. Em Repository access escolhe Only select repositories › pohmarketing. Em Permissions › Contents escolhe Read and write.
  4. Carrega em Generate token, copia a chave (começa por github_pat_) e cola aqui.
